# Artisanal AI plugins for Claude Code

Add the marketplace once, inside Claude Code:

```
/plugin marketplace add artisanal-ai/claude-plugins
```

Then install any plugin from it:

```
/plugin install <plugin>@artisanal-ai
```

## Plugins

| Plugin | What it does | Install |
| --- | --- | --- |
| [flex](https://github.com/artisanal-ai/flex) | Gym breaks for people who live in Claude Code: a stretch every few minutes, and pinky day every few prompts. | `/plugin install flex@artisanal-ai` |

To get new plugins and versions: `/plugin marketplace update artisanal-ai`.
